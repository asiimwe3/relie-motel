# Relie Motel — Fort Portal City, Uganda

Premium global-tourist website and direct-booking platform for Relie Motel (Malibo Road, Fort Portal, Uganda's Tourism City). This repo holds the plan, research and build for 2026–2029.

- `PLAN.md` — the 90-day sprint plan (Oct–Dec 2026): foreign-guest visibility in week 1, premium site by day 30, direct booking by day 60, growth engine by day 90
- `RESEARCH.md` — everything gathered from Relie Motel's online presence and Google Business Profile
- `REQUIREMENTS.md` — full requirements: languages, APIs, integrations, accounts checklist
- Future: website source (Next.js), Supabase schema, admin dashboard
